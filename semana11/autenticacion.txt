El login permite identificar a un usuario antes de darle acceso a determinadas funciones de la plataforma. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes. Esto evita que personas no autorizadas accedan al sistema. No deben exponerse públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles. De esta manera se protege la privacidad y la seguridad de la comunidad.
